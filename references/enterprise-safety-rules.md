# 企业安规（各电网/发电集团《电力安全工作规程》）使用规则

**核验基线：2026-10-11**（第二轮深挖，多路并进）。等级：`【已核验】`企业标准封面/正式出版物/官方平台；`【摘要级】`第三方站或文档站；`【未确认】`。

## 一、⚡ 核心使用规则（**用户指定企业时，直接用该企业的安规**）

1. **用户明确指定了企业**（如"国网的""华电的""南网的""国家电投的"）→ **直接采用该企业的《电力安全工作规程》作为作业依据**，不要再退回 GB 26860 / DL/T 408 泛泛而谈。企业安规是**现场执行的强制依据**，通常**严于且细于**国标行标。
2. **用户未指定企业** → 默认用 **GB 26860-2011 + DL/T 408/409/560-2023**，并**主动追问一句**："项目业主/运维方/施工方属于哪个集团？"——安规分册差异很大，追问能直接决定清单是否可用。
3. **绝不跨企业混用**：国网安规不能用于南网项目，华电安规不能套到国家电投场站。
4. **企业安规 ≠ 国标**：不满足企业安规 = 违反**合同与集团安全考核**；不满足 GB/DL = 违反**国家强制性标准**。**两者是并行约束，都要满足。**
5. **⚠️ 有 5 家集团公开渠道确实查不到集团级安规**（见第四、五节）。这些企业**不代表没有安规**，而是**内部文件不公开**或**直接执行国标**。遇到这 5 家，必须**向业主安全监督部门书面索取现行版本**，不得凭推测作答。

## 八、使用规则

1. **企业安规不公开、3—5 年一修**：引用时必须记录**标准号 + 版本年 + 发布日期**，并向企业安全监督部门索取现行版本。
2. **官方平台查不到企业标准是正常的**：全国标准信息公共服务平台查 `Q/GDW 1799` 返回 0 条，这是**企业标准不在收录范围**。
3. **第三方站的状态字段不可信**：同一站点既把已废止标准标"现行"，也把现行标准标"过期"。
4. **同一企业新旧编号并存**：国网 1799 与 10799 是两代编号；华电 16/19/20/21/22-2019 已被 85.1～85.5-2024 整体代替。
5. **遇到查不到的 5 家（国家能源集团、三峡、华润、国投、中国节能）**：明确告知用户"公开渠道无集团级安规，现场执行国标 GB 26860-2011 + DL/T 408-2023，需向业主安全监督部门书面索取内部版本"，**不要编造标准号**。
