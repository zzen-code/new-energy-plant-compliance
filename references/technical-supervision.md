## 一、技术监督是什么

电力技术监督是**贯穿建设期与运行期的强制性技术管理机制**：对设备全寿命周期的关键参数、试验数据、运行指标实施监测—评价—预警—整改。它不属于"审批手续"，而是**运行期合规与事故责任认定的核心证据链**，也是最容易被漏掉的一条线。

## 四、使用规则与陷阱

1. **新能源必须用新能源导则**：风电 NB/T 10110、光伏 NB/T 10113、储能 DL/T 2580；火电导则（DL/T 438、DL/T 561、DL/T 869 等）只能参照，不能作为合规依据。
2. **两处官方平台收录缺口（重大风险）**：**DL/T 596 与 DL/T 1054** 均未收录于 std.samr.gov.cn 行业标准库，平台仍把 2007/1996 旧版标"现行"。多源一致指向 **DL/T 596-2021** 与 **DL/T 1054-2021**，但只能标【摘要级】，**须以国家能源局标准公告复核**。
3. **官方平台不维护代替关系的情况**：DL/T 796-2012 与 DL 796-2001 同时标"现行"；DL/T 1100-2009 与 DL/T 1100.1-2018 并存；NB/T 31030-2022 与 NB/T 31030-2012 并存。遇到新旧同号并存，以"新版号存在即为现行"判断并复核。
4. **工程建设类标准不在国家平台**：GB 50xxx / GB 55xxx / GB/T 51xxx / JGJ 系列须查住建部公告或工程建设标准化信息网；计量规范（JJG）查 jjg.spc.org.cn；特种设备规范（TSG）查市场监管总局。
5. **关注"即将实施"**：DL/T 3069～3076—2026、DL/T 3084—2026、DL/T 5912/5913—2026、NB/T 12033—2026 均 **2026-12-26** 实施；GB/T 7261-2026 **2027-02-01**；GB/T 48213-2026 **2027-04-01**。跨期项目必须写明适用版本与切换日期。
