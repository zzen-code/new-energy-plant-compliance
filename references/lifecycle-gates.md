# 全生命周期分阶段闸门（Gate）与办理事项

用法：先锁定 **技术类型 / 装机容量与电压等级 / 所在省-市-县 / 当前阶段**，再逐阶段拉清单。**每个阶段的"必须完成项"缺一项就不得进入下一阶段**。
主管机关写的是常规对应关系，具体以属地规定为准（省级实施细则常常加码）。

---

## 阶段 0 前期规划与资源评估

| 事项 | 依据/说明 | 主管/受理 |
|---|---|---|
| 项目纳入省级/国家规划或年度建设方案 | 风电、光伏年度建设方案与竞争性配置文件 | 省能源局 / 国家能源局 |
| 资源评估（测风、辐照）、地形与地质初勘 | 行业标准与电网公司技术要求 | 企业自主 |
| 选址避让核查 | 永久基本农田、生态保护红线、自然保护地、I 级保护林地、军事设施、文物、民航净空、压覆矿产、采空区 | 自然资源 / 林草 / 生态环境 / 军事 / 民航 / 文物 |
| 消纳与接入初步意见 | 与电网公司沟通接入可行性 | 电网公司 |
